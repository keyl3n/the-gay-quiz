# THE GAY QUIZ
This is a cool gay quiz i made. I had claude make the points and ctrl+c systems cause i didnt have time to do them on call
## How 2 Run
- Go to the [releases page](https://github.com/keyl3n/the-gay-quiz/releases)
- Download the latest release, which is ![GitHub Release](https://img.shields.io/github/v/release/keyl3n/the-gay-quiz)
- Make sure you choose the correct one for your operating system
- Run the executable to start the quiz
> [!TIP]
> If you're running the quiz on Windows, try opening a terminal window in the folder that you downloaded the executable to and then running it from the terminal by typing `.\thegayquiz-win-x64.exe` and pressing Enter. This will prevent a bug that causes the quiz UI to use different symbols that make it look uglier.
