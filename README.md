# THE GAY QUIZ
This is a cool gay quiz i made. I had claude make the points and ctrl+c systems cause i didnt have time to do them on call
## How 2 Run
- Install Node.js at https://nodejs.org/en/download
- Install corepack with `npm install -g corepack`
- Run `corepack enable`
- Run `pnpm run setup`
- Start the quiz with `pnpm start`
